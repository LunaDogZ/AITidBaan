# ผลสุ่มตรวจ (2026-10-25)

ตามวิธีใน [docs/eval/spot-check.md](../../docs/eval/spot-check.md) ตรวจ 31 คำตอบ (ชีตละ 1) ผลดิบของ agent อยู่ที่ `check-accuracy.csv` และ `check-language.csv`

## สรุป

- **ตัวประเมินผิด 0 คำตอบจาก 31** (เกณฑ์ผ่านคือไม่เกิน 3) ทุกจุดที่ agent ยกคำมา ตรงกับหมายเหตุของตัวประเมิน หรือไม่ขัดกับระดับที่ให้
- ระดับตรงกันพอดี 24 จาก 31 อีก 7 คำตอบต่างกันหนึ่งระดับ ทุกคำตอบตัวประเมินให้ต่ำกว่า agent
- ข้อก้ำกึ่ง 1 ข้อจาก agent ตรวจภาษา: extraction-05 ค ตัวประเมินให้เขียว agent ภาษาเห็นว่าข้อ 5 เขียนไม่สมเหตุผล ("ไม่มีระบุในอีเมล เนื่องจากอาจต้องสอบถามเพิ่มเติม") แต่ agent ความแม่นยำให้ส่งได้เลย จึงไม่นับว่าผิด

## ต่างกันหนึ่งระดับ

| ข้อ | ป้าย | ตัวประเมิน | agent ความแม่นยำ | เรื่อง |
|---|---|---|---|---|
| minutes-01 | ก | แดง | แก้นิดหน่อย | วันในสัปดาห์ผิด 2 จุด |
| minutes-03 | ข | แดง | แก้นิดหน่อย | ชื่อเทศบาลผิดทั้งฉบับ แต่งเรื่องคณะรัฐมนตรี (agent เองบอกว่า "could reasonably be ทิ้ง") |
| summary-04 | จ | แดง | แก้นิดหน่อย | ตีความว่าเบิกให้บุตรได้คนเดียว |
| translation-01 | ก | แดง | แก้นิดหน่อย | แปลชนิดสินค้าผิด |
| translation-02 | ง | แดง | แก้นิดหน่อย | คำเพี้ยน "ไฟฟlicker" แปลชื่อบริษัท ความหมายผิด 1 ประโยค |
| translation-03 | ข | แดง | แก้นิดหน่อย | ไม่ได้แปลแต่สรุป และตกเรื่อง CFO |
| translation-04 | จ | เหลือง | ส่งได้เลย | ประโยค "Design a complete redesign" |

ทั้ง 7 ข้อ agent กับตัวประเมินเห็นจุดผิดเดียวกัน ต่างกันแค่ว่าหนักแค่ไหน ตัวประเมินยึดกฎข้อ 4 (ข้อเท็จจริงผิดจากต้นทาง → แดง) และกฎข้อ 11 (ไม่แน่ใจให้ระดับต่ำกว่า) ผลบนเว็บจึงน่าจะเข้มกว่าคนให้คะแนนทั่วไปเล็กน้อย
