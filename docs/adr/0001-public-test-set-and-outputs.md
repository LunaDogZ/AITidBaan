# เปิดชุดคำสั่งทดสอบ คำตอบของโมเดล และผลประเมินเป็นสาธารณะ

เราเผยแพร่ทุกอย่างที่ใช้ทำผลทดสอบภาษาไทย ได้แก่ คำสั่ง เอกสารที่แต่งขึ้น คำตอบดิบของโมเดล และผลประเมิน ภายใต้ CC BY 4.0 ส่วนโค้ดใช้ MIT ต่างจาก benchmark ทั่วไปที่มักเก็บชุดทดสอบไว้เป็นความลับ เหตุผลคือคุณค่าของเว็บอยู่ที่ความโปร่งใส ผู้ใช้ต้องเห็นคำตอบจริงจึงจะเชื่อผลประเมิน และการเปิดไว้ทำให้คนอื่นส่ง PR เพิ่มโมเดลหรือผลวัดความเร็วได้ ซึ่งคนทำคนเดียวทำเองไม่ไหว

## Consequences

- เรายอมรับความเสี่ยงที่โมเดลรุ่นหลังอาจถูกฝึกด้วยคำสั่งชุดนี้ จนได้คะแนนดีเกินจริง สำหรับโมเดลไทยตัวเล็ก เราประเมินว่าความเสี่ยงนี้ต่ำ ถ้าเกิดขึ้นจริง ให้แก้ด้วยการเพิ่มคำสั่งชุดใหม่ ไม่ใช่ปิดชุดเดิม
- เอกสารที่ใช้ทดสอบต้องเป็นของที่แต่งขึ้นเองทั้งหมด ห้ามใช้เอกสารจริงของบริษัทใด
