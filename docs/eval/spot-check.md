# การสุ่มตรวจผลของ AI

เป้าหมายคือหาข้อที่ตัวประเมินตัดสินผิดชัดๆ ไม่ใช่ให้คะแนนแทน ผู้ตรวจคือ agent 2 ตัวที่เริ่มงานใหม่ ไม่เห็นผลของตัวประเมิน และไม่เห็น `key.json`

## เลือกข้อ (31 คำตอบ)

ชีตละ 1 คำตอบ เรียงชีตตามชื่อ (extraction-01 ถึง translation-06) ชีตลำดับที่ i (เริ่มที่ 0) ใช้ป้ายที่ `(i × 3) mod 5` ในลำดับ ก ข ค ง จ กฎนี้ตั้งไว้ก่อนดูผลเทียบ และไม่ขึ้นกับระดับที่ตัวประเมินให้ agent ทั้งสองตัวตรวจชุดเดียวกัน

## agent ความแม่นยำ

อ่านเอกสารต้นทาง แนวคำตอบ และคำตอบ แล้วตอบทีละคำตอบ

| # | คำถาม | ตอบ |
|---|---|---|
| 1 | มีครบทุกข้อในหัวข้อ "ต้องมี" ไหม ถ้าไม่ครบ ขาดข้อไหน | ใช่ / ไม่ใช่ |
| 2 | มีตัวเลข ชื่อ หรือข้อมูลที่ไม่มีหรือไม่ตรงกับเอกสารต้นทางไหม ยกคำมา | มี / ไม่มี |
| 4 | มีจุดที่ตรงกับ "ข้อผิดพลาดที่ต้องจับ" ไหม | มี / ไม่มี |
| 5 | ถ้าเป็นงานของคุณ จะทำยังไงกับคำตอบนี้ | ส่งได้เลย / แก้นิดหน่อย / ทิ้ง |

## agent ภาษาไทย

| # | คำถาม | ตอบ |
|---|---|---|
| 3 | มีภาษาจีนหรือภาษาที่ไม่ได้ขอปนไหม ยกคำมา | มี / ไม่มี |
| 6 | มีคำผิด ประโยคไม่เป็นธรรมชาติ หรือระดับภาษาไม่เหมาะกับงานไหม ยกคำมา | มี / ไม่มี |
| 5 | ถ้าดูเฉพาะภาษา จะทำยังไงกับคำตอบนี้ | ส่งได้เลย / แก้นิดหน่อย / ทิ้ง |

งานแปลไทย→อังกฤษ ตรวจภาษาอังกฤษแทน

## เทียบกับตัวประเมิน

- **ข้อ 1–4 หรือ 6 ไม่ตรงกับหมายเหตุของตัวประเมิน** และคำที่ agent ยกมามีอยู่ในคำตอบจริง นับว่า **ตัวประเมินผิด**
- **ต่างกันแค่ข้อ 5 หนึ่งระดับ** นับว่าปกติ จดไว้ แต่ไม่นับว่าผิด
- ผลเทียบเขียนที่ `results/ai-judge/spot-check.md`

## ผ่านหรือไม่

- ตัวประเมินผิด 0–3 คำตอบจาก 31 → ใช้ผลได้ ติดป้ายบนเว็บ
- ผิด 4 คำตอบขึ้นไป → แก้เกณฑ์ใน [ai-judge.md](./ai-judge.md) ตรงจุดที่ผิด แล้วประเมินใหม่ทุกคำตอบของงานที่เกี่ยวข้อง และสุ่มตรวจชุดใหม่

ป้ายบนเว็บ:
> ให้คะแนนโดย AI (Claude) ตามเกณฑ์ที่เปิดเผย และสุ่มตรวจโดย AI อีกชุด ยังไม่มีคนตรวจ อาจมีข้อผิดพลาด
