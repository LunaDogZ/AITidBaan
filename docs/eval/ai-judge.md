# เกณฑ์ให้ AI ประเมินคำตอบ

ใช้แทนผู้ให้คะแนน 2 คนใน PRD 6.3 ขั้นที่ 5 เพราะหาคนไม่ได้ ไฟล์นี้เปิดเผยบนเว็บคู่กับผลทดสอบ

## วิธีรัน

1. ตัวประเมินคือ Claude Opus 5.5 อ่านชีตทีละข้อจาก `results/blind/sheets/` ห้ามเห็น `key.json` จึงไม่รู้ว่าคำตอบไหนมาจากโมเดลอะไร
2. ประเมินครบ 155 คำตอบรอบเดียว เขียนผลเป็น `results/ai-judge/scores.csv` รูปแบบเดียวกับ `results/blind/scores.csv`
3. agent อีก 2 ตัวสุ่มตรวจ โดยไม่เห็นผลของตัวประเมิน ตัวหนึ่งตรวจความแม่นยำ อีกตัวตรวจภาษาไทย (ดู [spot-check.md](./spot-check.md))
4. ผ่านการสุ่มตรวจแล้วจึงรัน `python3 scripts/export_site_data.py results/ai-judge/scores.csv results/ai-judge/scores.csv` (ใส่ไฟล์เดียวกันสองครั้ง เพราะสคริปต์รับผู้ให้คะแนน 2 คน)

## ระดับ

| ระดับ | ความหมาย |
|---|---|
| เขียว | ใช้ได้เลย ส่งต่อได้โดยไม่ต้องแก้ |
| เหลือง | ต้องแก้นิดหน่อย แก้ไม่เกินสองสามจุดก็ใช้ได้ |
| แดง | ใช้ไม่ได้ เขียนใหม่เองเร็วกว่า หรือส่งไปแล้วเกิดความเสียหาย |

## กฎ (เรียงตามลำดับความสำคัญ)

1. **ยึด "แนวคำตอบ" ของข้อนั้นก่อน** ถ้าแนวคำตอบระบุระดับไว้ (เช่น "→ ใช้ไม่ได้") ให้ใช้ตามนั้น กฎข้างล่างใช้กับเรื่องที่แนวคำตอบไม่ได้พูดถึง
2. **แต่งข้อมูลที่ไม่มีในเอกสารต้นทาง** ถ้าเป็นสาระที่ผู้รับจะใช้ตัดสินใจหรือทำตาม เช่น จำนวนเงิน ตัวเลข ชื่อคน วันนัด เงื่อนไข ข้อเสนอ → แดง ถ้าเป็นรายละเอียดประกอบที่ลบหรือแก้ได้ในจุดเดียว เช่น เวลาอบรม ชื่ออาคาร วันที่ในส่วนที่เล่าที่มา → เหลือง การเว้นช่องให้กรอก เช่น [ชื่อผู้ส่ง] ไม่นับว่าแต่ง
3. **ข้อหลอก** (extraction-04, extraction-05) ถ้าไม่ตอบว่าไม่มีระบุในเอกสาร → แดง
4. **ตัวเลขหรือข้อเท็จจริงผิดจากต้นทาง** → แดง
5. **มีภาษาที่ไม่ได้ขอปนมา** (เช่น ภาษาจีน) ปนแค่คำเดียว → เหลือง ปนทั้งประโยคขึ้นไป → แดง
6. **คำตอบซ้ำตัวเองทั้งก้อน หรือถูกตัดกลางคัน** → ประเมินจากว่าส่วนที่ขาดหรือส่วนที่ต้องลบมากแค่ไหน ถ้าขาดเนื้อหาที่ "ต้องมี" → แดง
7. **ตอบยาวไม่ได้ช่วยให้ได้คะแนนดีขึ้น** มีคำเกริ่น อธิบายเกินที่ถาม หรือมีหลายฉบับให้เลือก ทั้งที่ขอแค่ฉบับเดียว จนผู้ใช้ต้องตัดออกเอง → เหลือง คำเกริ่นหรือคำปิดบรรทัดเดียวที่อยู่นอกเนื้องาน (เช่น "แน่นอนครับ นี่คือตาราง") ไม่หัก
8. **ไม่ตัดสินจากการจัดรูปแบบ** มี markdown หรือไม่มีก็ได้ ถ้าเนื้อหาเท่ากัน ให้ระดับเท่ากัน
9. **ตรวจคำผิด** ยึดราชบัณฑิตยสภา ถ้าไม่แก้คำที่คนใช้จนชิน (เช่น อีเมล์) หักเบากว่าคำผิดอื่น
10. **ประเมินทีละคำตอบ** เทียบกับแนวคำตอบ ไม่ใช่เทียบกับคำตอบอื่นในชีตเดียวกัน
11. **ไม่แน่ใจระหว่างสองระดับ ให้เลือกระดับที่ต่ำกว่า**

## หมายเหตุ

ทุกคำตอบที่ไม่ได้เขียวต้องมีหมายเหตุ 1 ประโยค บอกจุดที่ผิดพร้อมยกคำจากคำตอบ เช่น `ใส่ "ถ้าโรงงานไม่เบี้ยวอีกรอบ" ในอีเมลถึงลูกค้า` เพื่อให้คนตรวจตามได้ว่า AI ให้ระดับนี้เพราะอะไร
