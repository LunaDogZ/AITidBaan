# AITidBaan
AI ติดบ้าน — ให้ AI อยู่ในเครื่องคุณ ไม่ต้องส่งเอกสารลับขึ้น Cloud · Thai benchmark &amp; guide for local LLMs

## ไฟล์ที่ไม่อยู่ใน git: `results/blind/key.json`

ไฟล์นี้บอกว่าป้าย ก ข ค ... ในชีตให้คะแนนคือโมเดลไหน จึงไม่ขึ้น git (ผู้ให้คะแนนต้องไม่เห็น) และมีอยู่ในเครื่องที่รัน `scripts/blind.py` เท่านั้น

- **สำรองไว้เอง** ในที่ที่ผู้ให้คะแนนเข้าไม่ได้ ถ้าหาย `scripts/export_site_data.py` จะจับคู่ผลประเมินกับโมเดลไม่ได้
- **ห้ามรัน `blind.py` ใหม่** เพื่อสร้างไฟล์นี้คืน เพราะป้ายจะสลับใหม่ ผลที่กรอกไปแล้วจะจับคู่ผิด
