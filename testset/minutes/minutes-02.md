## คำสั่ง
แปลงโน้ตนี้เป็นรายงานการประชุมแบบเป็นทางการหน่อย จะส่งให้ลูกค้าดูด้วย ขอวันที่ให้ชัดๆ นะ ไม่เอาแบบ "พฤหัสหน้า"

## เอกสารต้นทาง
kickoff เว็บรุ่งอรุณ  8/10/69 (พฤ) 14.00-15.40 @ออฟฟิศลค. บางนา

ลค. (บ.สวนเกษตรรุ่งอรุณ): คุณสมศักดิ์ (MD), คุณแพร (mkt mgr), คุณเอก (IT)
เรา (ไบต์ครีเอทีฟ): พี่โอ๋ PM, กาย dev lead, มิ้นท์ UX

- scope = เว็บ + ตะกร้าสินค้า + payment (QR / บัตร) / แอปมือถือยังไม่ทำ MD ยืนยันไว้คุยใน phase 2
- MD อยากเปิดก่อนปีใหม่ >> ตกลง go-live 15/12 **ถ้า** ลค.ส่ง content ครบตามกำหนด
- content รูปสินค้า+คำอธิบาย ประมาณ 120 SKU คุณแพรรับผิดชอบ ส่งภายในสิ้นเดือน
- คุณเอกถามเรื่อง host >> ใช้ cloud ของเรา ค่า host ปีแรกรวมในสัญญาแล้ว ปีที่ 2 เป็นต้นไปคิดแยก
  คุณเอกขอ spec server เป็นเอกสาร >> กายส่งให้ภายในวันจันทร์
- payment gateway ลค.ยังไม่ได้สมัคร >> คุณเอกไปยื่นสมัครกับธนาคาร ปกติใช้เวลา 2-3 wk ต้องได้ก่อน 20/11 ไม่งั้นเทสไม่ทัน
- มิ้นท์ทำ wireframe หน้าแรก + หน้าสินค้า นำเสนอพฤ.หน้า
- คุณแพรขอเว็บ 2 ภาษา TH/EN >> MD บอกเอาไทยก่อน EN ไว้ phase 2
- พี่โอ๋ทำ timeline ละเอียดส่งทุกคนภายในพรุ่งนี้
- ประชุมติดตามทุกพฤหัส 10 โมง ออนไลน์ทาง Teams

## แนวคำตอบ (สำหรับผู้ให้คะแนน)
ความยาก: ปานกลาง (ต้องแปลงวันที่สัมพัทธ์เป็นวันที่จริง ขยายคำย่อ และปรับภาษาให้เป็นทางการพอจะส่งลูกค้า)

วันประชุม: วันพฤหัสบดีที่ 8 ตุลาคม 2569 → การแปลงวันที่ที่ถูกต้อง:
- "พรุ่งนี้" = วันศุกร์ที่ 9 ตุลาคม 2569 (พี่โอ๋ส่ง timeline)
- "วันจันทร์" = วันจันทร์ที่ 12 ตุลาคม 2569 (กายส่ง spec server)
- "พฤ.หน้า" = วันพฤหัสบดีที่ 15 ตุลาคม 2569 (มิ้นท์นำเสนอ wireframe)
- "สิ้นเดือน" = ภายในวันที่ 31 ตุลาคม 2569 (คุณแพรส่ง content ~120 รายการ)
- payment gateway ต้องได้ภายใน 20 พฤศจิกายน 2569 (คุณเอก)
- go-live 15 ธันวาคม 2569 (มีเงื่อนไขว่าลูกค้าส่ง content ครบตามกำหนด)

ต้องมีด้วย:
- ผู้เข้าประชุมแยกฝ่ายลูกค้า (บริษัท สวนเกษตรรุ่งอรุณ: คุณสมศักดิ์ กรรมการผู้จัดการ, คุณแพร ผู้จัดการฝ่ายการตลาด, คุณเอก ฝ่ายไอที) และฝ่ายบริษัท ไบต์ครีเอทีฟ (พี่โอ๋/คุณโอ๋ ผู้จัดการโครงการ, คุณกาย หัวหน้าทีมพัฒนา, คุณมิ้นท์ UX)
- มติเรื่องขอบเขต: เว็บไซต์ + ตะกร้า + ชำระเงิน QR/บัตร; แอปมือถือและภาษาอังกฤษเลื่อนไป phase 2
- ค่า host ปีแรกรวมในสัญญา ปีที่ 2 ขึ้นไปคิดแยก
- ประชุมติดตามทุกวันพฤหัสบดี 10.00 น. ผ่าน Microsoft Teams

ข้อดีเพิ่ม: ตารางงาน/ผู้รับผิดชอบ/กำหนดส่ง, ใช้คำว่า "คุณโอ๋" แทน "พี่โอ๋" ในเอกสารที่ส่งลูกค้า, ขยายคำย่อ (ลค. → ลูกค้า, MD → กรรมการผู้จัดการ)

ข้อผิดพลาดที่ต้องดู:
- แปลงวันที่ผิด (เช่น พฤ.หน้า = 22 ต.ค., พรุ่งนี้ = 8 ต.ค.) — ผิดหนึ่งวันขึ้นไปถือว่าอย่างน้อยต้องแก้
- ตัดเงื่อนไขของ go-live ทิ้ง (เป็นประเด็นสำคัญเมื่อส่งลูกค้า)
- ยังใช้ภาษาย่อ/ภาษาพูดเยอะ (ลค., wk, >>) ในรายงานที่จะส่งลูกค้า
- แต่งนามสกุลหรือตำแหน่งที่ไม่มีในโน้ต
- เขียนว่าเว็บรองรับ 2 ภาษาตั้งแต่ phase 1
